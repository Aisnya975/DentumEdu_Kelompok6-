# Direktori Media Bahasa Isyarat SIBI

Tempatkan aset video MP4 atau gambar PNG untuk SIBI di folder ini.
Penamaan file sesuai id materi di `src/data/materi.json`:
- `a.mp4` / `a.png`
- `i.mp4` / `i.png`
- `u.mp4` / `u.png`
- `e.mp4` / `e.png`
- `o.mp4` / `o.png`
- `b.mp4` / `b.png`
- `p.mp4` / `p.png`
- `m.mp4` / `m.png`
- `mama.mp4` / `mama.png`
- `papa.mp4` / `papa.png`
- `bola.mp4` / `bola.png`
- `buku.mp4` / `buku.png`
- `makan.mp4` / `makan.png`
- `minum.mp4` / `minum.png`

Catatan: Komponen `SignPanel.tsx` secara otomatis menampilkan ilustrasi vektor interaktif SVG bila file video/gambar belum dimuat.
